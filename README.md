# 🎵 Jay Chou Music Player (周杰伦专属音乐播放器)

这是一个基于 HTML5, CSS3 和原生 JavaScript 打造的高颜值、响应式 Web 音乐播放器。项目以“磨砂玻璃”与“黑胶唱片”为核心设计语言，致敬华语乐坛天王周杰伦。

## ✨ 项目亮点

### 1. 极致的视觉体验 (S-Class Design)
*   **💎 玻璃拟态 (Glassmorphism)**：整体界面采用半透明磨砂玻璃风格，配合动态流动的渐变背景与全局噪点纹理（Noise Texture），营造出胶片电影般的复古质感。
*   **💽 拟真黑胶交互**：
    *   **机械唱臂系统**：纯 CSS 绘制的唱臂，播放时自动移向唱片，暂停时优雅复位。
    *   **物理质感唱片**：包含金属轴心、乙烯基纹理反光、以及嵌入式封面的内阴影处理。
*   **📝 沉浸式歌词**：
    *   **衬线体排版**：采用 Noto Serif SC 字体，配合居中对齐，呈现诗意美感。
    *   **景深效果**：高亮歌词清晰锐利，非当前歌词自动模糊处理，引导视觉焦点。
    *   **无缝遮罩**：歌词滚动区域上下边缘带有柔和的淡入淡出效果。

### 2. 细腻的微交互
*   **呼吸进度条**：播放时，进度条手柄会有节奏地“呼吸”闪烁，仿佛具有生命力。
*   **动态播放列表**：底部抽屉式播放列表，包含专辑缩略图及律动的音频波形动画。
*   **按压反馈**：控制按钮具备真实的按压回弹与光影变化。

## 🛠 技术栈

*   **HTML5**: 语义化标签构建播放器骨架。
*   **CSS3**: 
    *   使用 Flexbox 进行响应式布局。
    *   大量使用 `backdrop-filter` 实现毛玻璃效果。
    *   利用 `mask-image` 实现歌词遮罩。
    *   复杂的 `@keyframes` 动画与 `transition` 过渡。
*   **JavaScript (Vanilla)**:
    *   Audio API 控制音频播放、暂停、进度跳转。
    *   LRC 歌词解析与毫秒级同步滚动算法。
    *   **零依赖**：无需 Vue/React 或 jQuery，纯原生实现。

## 📂 目录结构

```text
jayChou/
├── index.html          # 项目入口，页面结构
├── style.css           # 核心样式表 (包含所有动画与响应式逻辑)
├── script.js           # 播放器核心逻辑 (播放控制、歌词同步)
├── lyrics_data.js      # 预处理的歌词数据 (解决本地 CORS 问题)
├── music/              # 存放 .mp3 音乐文件
├── imgs/               # 存放专辑封面图片
├── lyrics/             # 原始 .lrc 歌词文件
└── README.md           # 项目说明文档
```

## 🚀 如何运行

由于项目经过优化，解决了本地读取歌词文件的跨域 (CORS) 问题，您可以直接运行：

1.  双击打开 `index.html` 文件即可在浏览器中预览。
2.  推荐使用 Chrome, Edge 或 Safari 等现代浏览器以获得最佳的视觉体验。

## 🎨 设计细节展示

*   **唱片细节**：给封面图叠加了 `conic-gradient` 模拟放射状反光，并添加了 `box-shadow: inset` 内阴影，使其看起来是“嵌”在黑胶盘体中，而非贴在表面。
*   **氛围光感**：唱片背后的投影颜色会根据主题色（粉/紫）动态变化，形成悬浮的发光感。
*   **专属水印**：右下角手写体 "Jay Chou" 签名，增添品牌感。
